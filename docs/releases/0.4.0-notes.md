# Ond VS Code Extension 0.4.0

正式同梱のOndを0.4.0へ更新し、assemblyとroleの構文色分け、整数リテラル表示を更新しました。\
利用者向けの変更一覧は[CHANGELOG](../../CHANGELOG.md)、拡張の公開手順は[Marketplace公開](../marketplace-publishing.md)を参照してください。

## 変更

- `asm`／`asm noreturn`の構文色分けとrole文脈の補完
- 通常の名前として使う`asm`とrole変数の色分け修正
- 整数リテラルの基数接頭辞と桁区切りの色分け修正
- test file表示の特別扱いを除き、通常のOnd sourceとして処理
- 正式同梱のOnd 0.4.0との統合確認で`asm`の式補完、role文脈、test名を含むfileの通常補完、importとinterfaceの互換性を検査

## Ond 0.4.0の採用状態

正式配布用lockは[Ond 0.4.0 Release](https://github.com/SUPER-SHRINE/ond/releases/tag/0.4.0)のcommit `a40d63fd79219e8a4eee1be88821b6ac8fdc9e6f`を固定しています。\
lock SHA-256は`6f0669abca73ec5337d39f892fdbe1d2f6ba984964b17436d620f761c78fbab8`です。\
Windows/Linux両targetのarchive、checksum、Language Server binaryとproducer manifestを検証して採用しました。

公開前にWindows/Linux両hostで配布検証を完了する必要があります。\
先行するsource互換確認のcommit `7b23b7e1cc4338d8dced7d7545ef5aeaaf399546`は、正式Releaseの採用commitとは別の検証対象です。
