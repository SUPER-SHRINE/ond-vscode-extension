# Ond VS Code Extension 0.4.0

Ond 0.4.0 sourceとの統合確認を行い、assemblyとroleの構文色分け、整数リテラル表示を更新しました。\
利用者向けの変更一覧は[CHANGELOG](../../CHANGELOG.md)、拡張の公開手順は[Marketplace公開](../marketplace-publishing.md)を参照してください。

## 変更

- `asm`／`asm noreturn`の構文色分けとrole文脈の補完
- 通常の名前として使う`asm`とrole変数の色分け修正
- 整数リテラルの基数接頭辞と桁区切りの色分け修正
- test file表示の特別扱いを除き、通常のOnd sourceとして処理
- Ond 0.4.0 sourceとの統合確認で`asm`の式補完、role文脈、test名を含むfileの通常補完、importとinterfaceの互換性を検査

## Ond 0.4.0の採用状態

互換確認対象のOnd sourceはcommit `7b23b7e1cc4338d8dced7d7545ef5aeaaf399546`です。\
この確認では指定sourceからLanguage Serverをbuildし、非公開の検証用VSIXへ同梱します。\
正式配布用lockや公開経路には接続せず、正式配布用lockはOnd 0.3.0のままです。

Ond 0.4.0のGitHub Releaseは未公開です。正式採用にはOnd 0.4.0 Releaseの公開、正式lockの更新、およびWindows/Linux両hostでの配布検証が必要です。\
これらが完了するまで、正式配布物に同梱するOnd Language Serverは0.3.0です。
