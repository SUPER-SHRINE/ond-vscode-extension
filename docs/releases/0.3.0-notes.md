# Ond VS Code Extension 0.3.0

0.3.0向けの変更では、Ondのtest fileとproject/package構成に対応し、構文色分けと配布検証を更新しました。\
利用者向けの変更一覧は[CHANGELOG](../../CHANGELOG.md)、拡張の公開手順は[Marketplace公開](../marketplace-publishing.md)を参照してください。

## Ond 0.3.0との互換性

構文色分けでは`interface`を型keywordとして、削除済み`load32`／`store32`をbuiltinとして扱わなくなりました。\
project設定では必須の`[project].name`と、project名から始まるimport pathに対応します。\
依存packageは`ond.toml`の`[dependencies]`で登録してください。\
`OND_PATH`と`--library-dir`は依存指定に使いません。

旧interface型は具体型とfunction pointerへ、旧依存指定はmanifestの`[dependencies]`へ移行してください。\
project名、import、依存の定義は[Ond package仕様](https://github.com/SUPER-SHRINE/ond/blob/0.3.0/specs/ond/build/packages.md)と[名前・import仕様](https://github.com/SUPER-SHRINE/ond/blob/0.3.0/specs/ond/language/v1/names-and-scopes.md)を参照してください。
